# Pico 面部视频包交付测试

## 功能边界

本包运行在 Pico，负责按需全屏播放面部视频和显示字幕，不控制机械臂、底盘或急停。

- 开机后不自动播放；背屏 Firefox 应正常显示。
- 视频播放期间覆盖背屏；结束或停止后背屏恢复。
- 当前 Pico 未发现可用声卡，因此本包只验收画面和字幕。语音识别/合成应由 Orin 完成，再向字幕话题发布文本。

## ROS2 接口和字段

| 接口 | 类型 | 作用 |
| --- | --- | --- |
| `/zj_humanoid/robot/face_show/media_play` | `navi_robot_msgs/srv/FaceShow` | 按需播放图片/视频 |
| `/zj_humanoid/robot/face_show/media_stop` | `std_srvs/srv/Trigger` | 立即停止播放 |
| `/zj_humanoid/robot/face_show/status` | `std_msgs/msg/String` | 播放、停止、字幕状态 |
| `/zj_humanoid/subtitle/customer` | `std_msgs/msg/String` | 客户字幕 |
| `/zj_humanoid/subtitle/robot` | `std_msgs/msg/String` | 机器人字幕 |

在 Pico 上查看完整接口定义：

```bash
source /etc/nav01/Middleware.env
source /opt/ros/humble/setup.bash
ros2 interface show navi_robot_msgs/srv/FaceShow
ros2 interface show std_srvs/srv/Trigger
```

`FaceShow` 请求字段为 `media_path`（文件名）、`loop`（是否循环）、`duration`（秒，`0.0` 表示播放到自然结束）；响应字段为 `success`、`message`、`status_code`。`Trigger` 无请求字段，响应为 `success` 和 `message`。

## 部署

在 Pico 执行：

```bash
source /etc/nav01/Middleware.env
source /opt/ros/humble/setup.bash
cd ~/ros2_media_play_ws
colcon build --packages-select zj_media_play
sudo systemctl restart zj-media-play.service
systemctl --no-pager status zj-media-play.service
```

服务应为 `active (running)`，但不会播放视频，这是预期行为。

## 验收步骤
吗
先加载上面的 ROS2 环境。

### 不自动播放

重启 `zj-media-play.service` 后等待 10 秒。屏幕应仍显示背屏，不能自行弹出视频。

### 单次播放

先确认文件名：

```bash
ls -1 /opt/zj_humanoid/media_play
```

```bash
ros2 service call /zj_humanoid/robot/face_show/media_play \
  navi_robot_msgs/srv/FaceShow \
  "{media_path: '3-smile.mp4', loop: false, duration: 0.0}"
```

期望：返回 `success: true`；视频全屏显示；结束后回到背屏。

### 循环和定时结束

```bash
ros2 service call /zj_humanoid/robot/face_show/media_play \
  navi_robot_msgs/srv/FaceShow \
  "{media_path: '1-default.mp4', loop: true, duration: 5.0}"
```

期望：视频循环，约 5 秒后自动退出。

### 替换播放与手动停止

播放循环视频后调用另一段视频，应由后一段替换前一段，不能叠加播放器。

```bash
ros2 service call /zj_humanoid/robot/face_show/media_stop std_srvs/srv/Trigger '{}'
```

期望：返回 `success: true`，视频立即退出，背屏恢复。

### 字幕

字幕只能在视频正在播放时显示：

```bash
ros2 topic pub --once /zj_humanoid/subtitle/customer std_msgs/msg/String \
  "{data: '你好，机器人'}"

ros2 topic pub --once /zj_humanoid/subtitle/robot std_msgs/msg/String \
  "{data: '你好，我在这里'}"
```

期望：字幕在画面顶部显示约 5 秒；客户字幕带“用户：”，机器人字幕带“机器人：”。没有视频时字幕被忽略是预期行为。


### 接口状态检查

```bash
ros2 service list | grep face_show
ros2 topic type /zj_humanoid/robot/face_show/status
ros2 topic echo --once /zj_humanoid/robot/face_show/status
```

期望：能看到 `media_play`、`media_stop` 两个服务；状态类型为 `std_msgs/msg/String`。播放、停止、字幕操作时，状态话题应分别出现 `playing:...`、`stopped` 或 `subtitle:...`。
